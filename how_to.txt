# How to Set Up and Run the AI Trading Project

This guide will walk you through the entire process of setting up and running the AI Trading Project on a Linux system. It's written for complete beginners, so we'll go through each step in detail.

## Chapter 1: Setting Up on Linux

### Step 1: Install a modern web browser

You will need a modern web browser such as Firefox or Chrome to sign up for an LN Markets account.

### Step 2: Install Git, Python, and other required packages

You will need to have `git` and `python3` installed to get started. Most modern Linux distributions come with these pre-installed. You will also need to install `wget`, `make`, `gcc`, and `g++`.

To check if you have these, open a terminal and run the following commands:

```bash
git --version
python3 --version
wget --version
make --version
gcc --version
g++ --version
```

If any of these commands give you an error, you will need to install them. On a Debian-based distribution such as Ubuntu, you can do this by running the command below:

```bash
sudo apt-get update && sudo apt-get install -y git python3-pip wget make gcc g++
```

### Step 3: Clone the project repository

This will download a copy of the project to your local machine.

```bash
git clone https://github.com/tristantheb/trading-ai-project.git
```

Once the download is complete, navigate to the project directory:

```bash
cd trading-ai-project
```

### Step 4: Run the installation script

The project comes with an installation script that will automatically install all the required dependencies.

First, make the script executable:

```bash
chmod +x install.sh
```

Now, run the script:

```bash
./install.sh
```

This script will do the following:

1.  Download and install the TA-Lib C library, which is required for the technical analysis functionality.
2.  Install all the required Python libraries from the `requirements.txt` file.
3.  Run a verification script to make sure everything is installed correctly.

### Step 5: Set up your LN Markets testnet account

To use the live trading functionality, you will need to create an account on the LN Markets testnet. This will allow you to test the trading bot without risking real money.

1.  Go to the [LN Markets testnet website](https://testnet.lnmarkets.com/).
2.  Click on the **Sign up** button and follow the instructions to create an account.
3.  Once you have created your account, go to the **API** section to get your API keys.
4.  You will need to generate a new set of API keys. Give them a name (e.g., "trading-bot") and make sure to copy the `key`, `secret`, and `passphrase`.

### Step 6: Configure your API keys

Now that you have your API keys, you need to add them to the project.

1.  Open the `trading_ai_project/api/lnmarkets_client.py` file in a text editor.
2.  Find the `options` dictionary and replace the placeholder values with your actual API keys.

```python
# trading_ai_project/api/lnmarkets_client.py

options = {
    'key': 'YOUR_API_KEY',
    'secret': 'YOUR_API_SECRET',
    'passphrase': 'YOUR_API_PASSPHRASE',
    'network': 'testnet'  # Use 'mainnet' for real trading
}
```

### Step 7: Run the project scripts

Now that everything is set up, you can run the main scripts.

**Train the agent**

This will train the reinforcement learning agent on the historical data.

```bash
python3 train_agent.py
```

This will save the trained model to `trading_ai_project/models/ppo_trading_agent.zip`.

**Evaluate the agent**

This will evaluate the trained agent's performance on the historical data.

```bash
python3 evaluate_agent.py
```

**Run a backtest**

This will run a simple backtest with random actions.

```bash
python3 backtest.py
```

**Inspect the LN Markets API connection**

This will test your connection to the LN Markets API.

```bash
python3 inspect_client.py
```

If your API keys are configured correctly, you should see a success message and your user information.

## Chapter 2: Setting Up on Windows with WSL

This chapter will guide you through setting up the project on a Windows machine using the Windows Subsystem for Linux (WSL). WSL allows you to run a Linux environment directly on Windows, which is the recommended way to run this project on a Windows machine.

### Step 1: Install WSL

1.  Open PowerShell as an administrator.
2.  Run the following command to install WSL:

    ```bash
    wsl --install
    ```

3.  This will install the default Ubuntu distribution of Linux. Once the installation is complete, you will need to restart your computer.
4.  After restarting, a new Ubuntu terminal window will open. You will be prompted to create a new username and password. This will be your user account for the Linux environment.

### Step 2: Follow the Linux setup guide

Once you have WSL installed and have a terminal open, you can follow the same steps as in the Linux setup guide (Chapter 1). The only difference is that you will be working inside the WSL terminal instead of a regular Linux terminal.
